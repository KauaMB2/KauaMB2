<h3>⚙️ Fullstack Platform</h3>
<p><strong>Fullstack & Mobile</strong></p>
<p>

<h3>🌐 ISP Automation Platform</h3>
<p><strong>Automations, Cron Jobs & AI</strong></p>
<p>
A fullstack customer service automation ecosystem I built and maintained for an internet service provider (ISP): several services running in Docker containers on the same VPS.
</p>
<p>
At its core is an LLM-powered WhatsApp bot integrated with Chatwoot covering sales and support. It identifies the customer, sends PIX and bank slips, grants trust-based unblocking, analyzes the router photo with computer vision, restarts the equipment through the OLT and opens typed technical tickets. Microservices implement the same API contract for different ERPs, with a router that sends each call to the system where the customer actually exists.
</p>
<p>
Around it run eight scheduled jobs (post-service follow-ups on D+1, D+7, D+15 and D+30, reply polling, periodic syncs, alerts and reports) and a multi-tenant dashboard that analyzes conversations with AI and flags churn risk. Everything is layered with dependency injection, backed by a ten-pillar CI quality gate and unit, integration and end-to-end tests, and deployed with Docker Compose, Jenkins and GitHub Actions.
</p>

<h3>🤖 Judite</h3>
<p><strong>Frontend & Backend</strong></p>
<p>
Judite is a web platform created to automate business customer service, integrating WhatsApp, Messenger, Instagram Direct and Webchat through Meta's official API. It reached nearly 10,000 chats opened and an average of 100 daily contacts.
</p>
<p>
The system offers automatic responses, scheduled messages, a metrics dashboard, contact management and complete configuration of AI agents, including personality, tools and operating parameters. Agents get dynamic context from videos, websites, PDFs, Word documents or free text, plus a vector database (RAG) for answers aligned with each company's products and services.
</p>
<p>
It integrates with external services such as Correios, Google Sheets, Freshdesk, Brasil API and Asaas, on a modular architecture with DevOps practices.
</p>

<h3>📷 RTSP Detector</h3>
<p><strong>Classification, Detection & Facial Recognition</strong></p>
<p>
RTSP Detector is software that turns any security camera into an alarm center via the RTSP protocol. A real-time classifier labels each frame as "Fire", "With person" or "Without person". When a person is suspected, a detector confirms the presence and a third model checks for firearms or knives.
</p>
<p>
It also features facial recognition, so registered residents and employees can be told apart from unknown people. When an event is detected, a message is automatically sent to the user's WhatsApp with the exact frame where it occurred. All models were trained by me, and the interface and backend were built with HTML, CSS, JavaScript, Electron and Python. Currently running on 17 cameras.
</p>
